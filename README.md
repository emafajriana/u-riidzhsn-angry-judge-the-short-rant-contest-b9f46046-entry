Entry for the [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun.

`main.py` (Python 3.13, standard library only) writes one short, funny rant about a small everyday annoyance to `/output/entry.txt`: the self-checkout machine that scans your milk, weighs your bag, and still screams "unexpected item in the bagging area" at crisps you haven't even touched.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```
